## Перед началом (на компьютере)

1. Закройте старый сервер (порт 8787), если он запущен.
2. Для распознавания речи: запустите `whisper-server` как раньше (см. `docs/ASR_DESIGN.md`). Для проверки без модели: в `.env` поставьте `ASR_ENGINE=mock`.
3. Запустите: `npm run dev:lan:app` (установка на экран) — или `npm run dev:lan` (обычный режим).
4. Телефон — в той же Wi-Fi сети. Данные для входа — в `data/demo-credentials.txt` (только на компьютере, никуда не отправляйте). Код из приложения-аутентификатора для вымышленного пользователя генерируется тем же способом, что на компьютере.
